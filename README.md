# Portafolio Personal 

Portafolio web interactivo desarrollado con React, Vite y Ant Design, estructurado como una Single Page Application (SPA) vertical bajo el patrón **Atomic Design**.

## Requisitos Previos
- [Node.js](https://nodejs.org/) (versión 18 o superior)
- npm

## Instalación y Ejecución

1. Instala las dependencias: npm install
2. Inicia el servidor local de desarrollo: npm run dev
3. Test: run test
